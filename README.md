# ssh-tool

一个小型服务器工具脚本：SSH 端口、密钥、密码登录管理，系统信息，CPU / 内存 / 硬盘性能检测，BBR 加速，禁 Ping，TCP/UDP 端口转发，回程线路和流媒体 / AI 解锁检测。

所有功能都只在你选择时运行，不装后台服务、不常驻进程。

## 一键安装并启动

```bash
curl -fsSL https://raw.githubusercontent.com/chentiti888/ssh-tool/main/ssh-tool.sh -o /usr/local/bin/ssb && chmod +x /usr/local/bin/ssb && ssb
```

这条命令会把脚本下载为快捷命令 `ssb` 并直接打开菜单，之后在任意目录输入：

```bash
ssb
```

> 先下载成文件再运行，快捷命令一定会保存下来。
> 脚本带交互菜单，不要用 `curl ... | bash`，否则菜单无法读取输入。
> 需要 root 权限运行。

## 功能

主菜单分 5 类：

```
 1) 系统信息
 2) SSH 安全      端口 / 密钥 / 密码登录
 3) 性能检测      CPU 占用 / CPU / 内存 / 硬盘
 4) 网络设置      BBR / 禁 Ping / 端口转发
 5) 网络检测      回程线路 / 流媒体 / AI 解锁
 6) 更新脚本
 0) 退出
```

### 1) 系统信息

系统、内核、虚拟化类型、CPU、内存、Swap、硬盘、运行时长、BBR 状态、SSH 端口、密码登录、Ping 状态、公网 IPv4/IPv6。

### 2) SSH 安全

| 菜单 | 功能 | 说明 |
| --- | --- | --- |
| 1 | 修改 SSH 端口 | 检查端口合法性和占用，自动备份配置，自动放行防火墙，校验失败自动回滚 |
| 2 | 生成密钥 | 支持 ed25519（推荐）和 rsa 4096，可设密码，公钥自动加入 `authorized_keys` |
| 3 | 导入公钥 | 从仓库拉取（默认 `chentiti888/gy` 的 `authorized_keys`，可在菜单里改地址）或手动粘贴；只追加新公钥、不删原有的，导入前显示指纹并备份；发现私钥会拒绝导入 |
| 4 | 下载已有密钥 | 显示私钥内容 / 一次性临时 HTTP 链接 / 显示 scp 命令 |
| 5 | 禁用密码登录 | 仅保留密钥登录，`authorized_keys` 为空时拒绝执行 |
| 6 | 恢复密码登录 | 连云厂商的 cloud-init 配置一起改；root 被限制只能用密钥、或 root 没有密码时会提示处理 |

### 3) 性能检测

| 菜单 | 功能 | 说明 |
| --- | --- | --- |
| 1 | CPU 占用状态 | 采样几秒算出真实占用：各核占用条、占用细节（用户程序 / 系统内核 / 等待硬盘 / 网络中断 / 被宿主占用，每项附说明）、最耗 CPU 的前 10 个程序和完整命令，并给出结论；可实时刷新 |
| 2 | CPU 性能测试 | 单核 / 多核得分（sysbench，可和常见 VPS 测评对比），多核倍数，被宿主占用（超售参考） |
| 3 | 内存性能测试 | 单线程读 / 写、多线程读 / 写速度（sysbench，各 5 秒）；只反复读写一小块内存，不会占满内存；没有 sysbench 时用 dd 粗测 |
| 4 | 硬盘 IO 测试 | `dd` 写入 3 次 + 读取 1 次，临时文件测完自动删除，空间不足时自动缩小测试量 |

### 4) 网络设置

| 菜单 | 功能 | 说明 |
| --- | --- | --- |
| 1 | BBR 加速 | 开启 / 关闭，重启后保持；内核太旧或容器 VPS 不支持时会说明原因 |
| 2 | 禁 Ping | 禁用 / 恢复回应 ping（IPv4 和 IPv6），重启后保持；只关 ping 回应，网站、SSH、代理不受影响；用 ping 做监控的工具会显示离线 |
| 3 | 端口转发 | TCP+UDP / 仅 UDP / 仅 TCP 转发的添加、删除、清空、查看，重启后自动恢复 |

### 5) 网络检测

| 菜单 | 功能 | 说明 |
| --- | --- | --- |
| 1 | 回程线路检测 | 从本机 traceroute 到北京 / 上海 / 广州 / 成都的电信、联通、移动（共 12 条，并行约 30 秒），按途经的骨干网判断线路：电信 CN2 GIA / CN2 GT / CTGNET / 163，联通 9929 / CUG / 4837，移动 CMIN2 / CMI / CMNET；可查看任意一条的逐跳详情。判断规则参考 [oneclickvirt/backtrace](https://github.com/oneclickvirt/backtrace)。去程要从国内测，会给出 ITDOG 的检测链接 |
| 2 | 流媒体 / AI 解锁 | Netflix、Disney+（简易判断）、YouTube Premium、Prime Video，ChatGPT、Claude、Gemini，可选 IPv4 / IPv6，约 10 秒；判断方法参考 [lmc999/RegionRestrictionCheck](https://github.com/lmc999/RegionRestrictionCheck)，也可以直接调用它做完整检测（第三方脚本，会先确认） |

> 结果是按路由 IP 段和平台网页特征推测的，平台改版后可能不准，仅供参考。

### 6) 更新脚本

从仓库拉取最新版并重新打开（按最新提交下载，不受 GitHub 缓存影响）。

### 新服务器推荐流程

1. 运行一键安装命令，进入菜单。
2. 进 **SSH 安全 → 3** 从仓库导入你的公钥。
3. **新开一个终端**，用私钥测试能登录。
4. 进 **SSH 安全 → 1** 改 SSH 端口（同样先测试再关旧窗口），再用 **SSH 安全 → 5** 禁用密码登录。

## 使用说明

### 修改 SSH 端口

1. 进 **SSH 安全 → 1**，输入新端口（1-65535）。
2. 脚本自动备份 `/etc/ssh/sshd_config`，写入新端口，并放行 ufw / firewalld / iptables。
3. **不要关闭当前终端**，新开一个窗口测试：

   ```bash
   ssh -p 新端口 root@服务器IP
   ```

4. 云服务器还需要在控制台**安全组 / 防火墙**中放行新端口。
5. 确认新端口能登录后，再关闭旧端口。

### 生成并下载密钥

1. 进 **SSH 安全 → 2**，输入密钥名称、类型和密码（可留空）。
2. 密钥保存在 `/root/.ssh/keys/`，公钥自动写入 `/root/.ssh/authorized_keys`。
3. 按提示选择下载方式：
   - **显示私钥内容**：复制全部内容（含 BEGIN / END 行）保存为本地文件，最安全。
   - **临时 HTTP 链接**：一次性，下载一次或 120 秒后自动关闭。为明文传输，用完建议重新生成密钥。
   - **scp 命令**：在本地电脑执行脚本给出的命令。
4. 本地使用密钥登录：

   ```bash
   chmod 600 私钥文件
   ssh -i 私钥文件 -p 端口 root@服务器IP
   ```

### 禁用密码登录

进 **SSH 安全 → 5**。务必先用密钥成功登录一次，再执行此项，否则可能无法登录服务器。

## 注意事项

- 修改端口、禁用密码登录前，保留一个已登录的终端窗口作为后路。
- 每次修改前，`sshd_config` 都会备份为 `/etc/ssh/sshd_config.bak.时间戳`。
- 私钥属于敏感信息，下载后请妥善保管，不要发给他人。

## 更新

在主菜单选 `6` 即可更新到仓库最新版。也可以重新执行上面的一键安装命令。

发布新版时，请顺手修改脚本开头的 `TOOL_VER="..."`，更新时会显示 `当前 vX → 仓库 vY`。

## 自定义

- 快捷命令名：修改脚本中的 `CMD_NAME="ssb"`。
- 仓库地址：修改脚本中的 `SCRIPT_URL`，用于通过 curl 运行时自动安装快捷命令和菜单里的更新。
- 公钥地址：**SSH 安全 → 3 导入公钥 → 3 修改拉取地址**。可以填 `用户名/仓库名`、GitHub 文件网页地址、GitHub 用户名（取账号里登记的公钥）或任意 https 直链，保存前会试拉一次；改过的地址存在 `/etc/ssh-tool.conf`，更新脚本不会丢，输入 `default` 恢复默认。这个仓库**只能放公钥**；能修改它的人就能决定谁能登录你的服务器，请给 GitHub 账号开启两步验证。
