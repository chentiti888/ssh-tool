# ssh-tool

一个小型 SSH 管理脚本：修改 SSH 端口、生成密钥并下载、禁用密码登录。

## 一键安装并启动

```bash
curl -fsSL https://raw.githubusercontent.com/chentiti888/ssh-tool/main/ssh-tool.sh -o /usr/local/bin/chen && chmod +x /usr/local/bin/chen && chen
```

这条命令会把脚本下载为快捷命令 `cc` 并直接打开菜单，之后在任意目录输入：

```bash
chen
```

> 先下载成文件再运行，快捷命令一定会保存下来。
> 脚本带交互菜单，不要用 `curl ... | bash`，否则菜单无法读取输入。
> 需要 root 权限运行。

## 功能

| 菜单 | 功能 | 说明 |
| --- | --- | --- |
| 1 | 修改 SSH 端口 | 检查端口合法性和占用，自动备份配置，自动放行防火墙，校验失败自动回滚 |
| 2 | 生成密钥 | 支持 ed25519（推荐）和 rsa 4096，可设密码，公钥自动加入 `authorized_keys` |
| 3 | 下载已有密钥 | 显示私钥内容 / 一次性临时 HTTP 链接 / 显示 scp 命令 |
| 4 | 禁用密码登录 | 仅保留密钥登录，`authorized_keys` 为空时拒绝执行 |
| 0 | 退出 | |

## 使用说明

### 修改 SSH 端口

1. 选择 `1`，输入新端口（1-65535）。
2. 脚本自动备份 `/etc/ssh/sshd_config`，写入新端口，并放行 ufw / firewalld / iptables。
3. **不要关闭当前终端**，新开一个窗口测试：

   ```bash
   ssh -p 新端口 root@服务器IP
   ```

4. 云服务器还需要在控制台**安全组 / 防火墙**中放行新端口。
5. 确认新端口能登录后，再关闭旧端口。

### 生成并下载密钥

1. 选择 `2`，输入密钥名称、类型和密码（可留空）。
2. 密钥保存在 `/root/.ssh/keys/`，公钥自动写入 `/root/.ssh/authorized_keys`。
3. 按提示选择下载方式：
   - **显示私钥内容**：复制全部内容（含 BEGIN / END 行）保存为本地文件，最安全。
   - **临时 HTTP 链接**：一次性，下载一次或 120 秒后自动关闭。为明文传输，用完建议重新生成密钥。
   - **scp 命令**：在本地电脑执行脚本给出的命令。
4. 本地使用密钥登录：

   ```bash
   chmod 600 私钥文件
   ssh -i 私钥文件 -p 端口 root@服务器IP
   ```

### 禁用密码登录

选择 `4`。务必先用密钥成功登录一次，再执行此项，否则可能无法登录服务器。

## 注意事项

- 修改端口、禁用密码登录前，保留一个已登录的终端窗口作为后路。
- 每次修改前，`sshd_config` 都会备份为 `/etc/ssh/sshd_config.bak.时间戳`。
- 私钥属于敏感信息，下载后请妥善保管，不要发给他人。

## 自定义

- 快捷命令名：修改脚本中的 `CMD_NAME="chen"`。
- 仓库地址：修改脚本中的 `SCRIPT_URL`，用于通过 curl 运行时自动安装快捷命令。
